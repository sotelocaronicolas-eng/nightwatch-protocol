# Módulo 5 · Glosario técnico español → inglés (BORRADOR)

Uso: Claude Code lo sigue al redactar el inglés (etapas 8 y 9); cada integrante del grupo revisa un módulo. **Todo término de esta tabla es PROPUESTA hasta que el grupo lo apruebe.**
Reglas: (1) un término = una traducción en toda la app; (2) los **comandos de laboratorio no se traducen** (`ufw allow 22/tcp`, `ping`, etc.); (3) los nombres propios
(NightWatch Protocol, CiberMynd, Iceland/Inter) y los emojis no cambian; (4) los nombres de islas, insignias y niveles se traducen como aparecen abajo; (5) tono: segunda persona, frases cortas.
